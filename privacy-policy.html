Privacy Policy for TraceFence

Last updated: July 13, 2026

Thank you for using TraceFence ("we", "our", or "the App"). This Privacy Policy explains how TraceFence handles information in the macOS and iOS applications, including optional website subscriptions.

Key Principle: Agent activity and conversation data stay on devices you control. TraceFence does not operate an analytics, advertising, agent-data, or remote-control backend.

1. Information We Collect

TraceFence is designed as a local-first application. We do not upload your agent conversations, project files, command history, approval content, or monitoring records to a TraceFence server. Network requests occur only for the user-selected services described below.

2. Data You Optionally Provide

2.1 AI Analysis Feature (User-Configured)

TraceFence offers an optional AI-powered analysis feature that requires you to provide:

  • LLM API Key — Your own API key for services like DeepSeek, OpenAI, or other compatible providers
  • API Base URL — The endpoint URL of your chosen LLM service

This information is:

  • Stored only on your Mac in the app's sandbox container
  • Used only when you explicitly trigger an AI analysis action
  • Transmitted directly from your Mac to your chosen LLM provider — we never see or relay this data
  • Subject to the privacy policy of your chosen LLM provider

Important: We do not operate any AI servers. All AI requests go directly from your Mac to the LLM provider you configure. We have no access to your API keys or the data sent to LLM providers.

2.2 No Account Required

TraceFence does not require a TraceFence account. Website subscribers provide billing details directly to Dodo Payments, and App Store subscribers provide purchase details to Apple under those providers' terms.

3. Data Storage and Security

3.1 Local Storage

App data is stored in the applicable TraceFence Application Support directory or App Store container on your device. Website license secrets are stored in macOS Keychain.

3.2 Data Retention

  • Operation records and lifecycle events are retained until you clear them within the app
  • Hourly statistics are retained for trend analysis until you clear them
  • Configuration data (rules, settings) persists until you modify or delete it
  • Uninstalling the app removes all stored data

3.3 Security Measures

  • The Mac App Store build uses App Sandbox; the website build uses hardened runtime and user-granted macOS permissions
  • Security-scoped bookmarks used for file monitoring — access limited to user-authorized directories
  • Local-only Agent Center listener — the app may listen on localhost or a Unix domain socket so AI agent hooks on your Mac can send approval requests to the app; it does not accept internet-facing connections
  • Hardened runtime enabled — prevents dynamic code injection

5. Third-Party Services

TraceFence does not integrate with third-party analytics or advertising services. External services used for specific functions are:

  • Apple Mac App Store — For app distribution and updates, subject to Apple's Privacy Policy
  • Dodo Payments — Merchant of Record, checkout, billing, tax, invoices, and license-key lifecycle for the website subscription, subject to Dodo Payments' Privacy Policy
  • GitHub — Website documentation and release downloads for the website build, subject to GitHub's Privacy Statement
  • Your chosen LLM provider — Only if you configure the optional AI analysis feature, subject to that provider's privacy policy

6. File System Access

TraceFence monitors file system activity in user-authorized directories (Desktop, Documents, Downloads, project folders, etc.) to track AI agent operations. This access is:

  • Used solely for displaying file operation audit trails to you
  • Never transmitted externally
  • Implemented using macOS FSEventStream API with security-scoped bookmarks
  • Revocable by disabling the Operation Monitor in Settings

7. Children's Privacy

TraceFence is not directed to children and does not knowingly collect information from children under 13.

8. Your Rights and Choices

You have full control over your data:

  • View — All collected data is visible within the app's interface
  • Delete — You can clear operation records, lifecycle events, and statistics at any time from within the app
  • Disable — You can disable monitoring features (Operation Monitor, Hardware Monitor, Sensor Monitor) in Settings
  • Uninstall — Removing the app deletes all locally stored data
  • AI Feature — You can remove your API key at any time to disable AI analysis

9. International Users

TraceFence is available globally. Dodo Payments, Apple, GitHub, your chosen AI provider, and any user-selected VPN or tunnel may process data across borders under their respective privacy terms.

10. Compliance

We do not operate a server that receives your agent or project data. Billing providers may independently process customer and transaction data as described above.

CCPA (California Consumer Privacy Act)

We do not sell, share, or disclose personal information as defined by CCPA, as we do not collect such information.

Apple App Store Requirements

We comply with Apple's App Store Review Guidelines and privacy requirements, including the App Privacy Declaration.

11. Privacy Declaration (Apple App Store)
