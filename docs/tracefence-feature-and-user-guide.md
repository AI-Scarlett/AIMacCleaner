# TraceFence 功能文档与使用手册

更新日期：2026-07-01  
适用产品：TraceFence macOS 版  
适用版本：App Store 版 3.1.x、独立分发版 1.0.x

> 本文档按当前产品实际入口整理，用于产品介绍、客服支持、用户手册和官网内容拆分。独立分发版指通过 TraceFence 官网或 GitHub Releases 下载的版本；App Store 版指通过 Mac App Store 下载的版本。

## 1. 产品定位

TraceFence 是面向 AI Agent 用户、开发者和重度 macOS 用户的本机可视化与安全管理工具。它把 AI Agent 会话、Token 用量、Provider 额度、文件操作、运行状态、清理空间、应用和依赖管理放在同一个原生 macOS 应用里。

TraceFence 的核心目标是：

- 看清 AI Agent 在本机留下了什么数据。
- 看清 AI Agent 正在消耗多少 Token、额度和磁盘空间。
- 及时发现高风险操作、异常文件访问、敏感目录变更和运行状态问题。
- 在用户明确授权的前提下，帮助备份、诊断、清理和修复。
- 尽量使用本机数据、本机权限和系统能力，不把用户会话内容上传到远端。

## 3. 数据与隐私原则

TraceFence 默认遵守以下原则：

- 只读取用户明确授权的本机目录。
- 主要分析本机日志、状态库、文件元数据和运行进程。
- 不读取或展示密钥、Token、Cookie 的明文内容。
- 会话备份默认排除凭证类文件。
- 删除、清理、进程终止、重启等高风险操作都需要用户确认。
- 清理操作默认优先移动到废纸篓，而不是直接永久删除。
- Token 成本是本地估算值；Provider 额度来自官方接口或本机已登录状态。

## 4. 主窗口功能

### 4.1 概览

概览页是 TraceFence 的指挥中心，用于快速查看当前 AI Agent 工作区状态。

主要能力：

- 展示已聚合会话数、活跃 Agent 数、项目数和 Token 总量。
- 使用图表块展示关键指标，而不是重复堆叠文本。
- 显示当前活跃会话、近期使用趋势和数据源状态。
- 支持手动刷新和重新授权数据目录。
- 发现没有权限、没有数据或正在扫描时，会给出对应状态提示。

适合场景：

- 想快速判断今天 AI Agent 是否还在运行。
- 想知道当前有多少会话、项目和 Token 消耗。
- 想检查 TraceFence 是否已经读取到本机数据源。

### 4.2 Agent 守护

Agent 守护用于监控 AI Agent 的安全状态、文件操作和规则命中情况。

页面包含以下子模块：

- 守护概览
- 告警中心
- 告警规则
- 命令规则
- 保护目录
- Agent 工具箱

#### 守护概览

守护概览会汇总：

- 未读告警数量
- 高危告警数量
- 总告警数量
- 操作记录数量
- 最近告警
- 最近操作趋势

用户可以在这里快速判断是否出现异常文件操作、敏感路径访问、批量删除或高风险命令。

#### 告警中心

告警中心用于集中处理风险事件。

支持能力：

- 按全部、高危、警告、提示过滤。
- 查看告警来源、时间、路径和风险等级。
- 标记全部已读。
- 清空告警。
- 导出告警 CSV。
- 生成审计报告。

#### 告警规则

告警规则用于控制 TraceFence 什么时候提醒用户。

可配置项包括：

- 批量删除阈值
- 批量修改阈值
- 监控时间窗口
- 告警冷却时间
- 敏感文件检测
- 敏感内容检测
- 进程启动告警
- 保护目录告警
- 系统通知
- 勿扰模式

#### 命令规则

命令规则用于识别和处理高风险命令。

支持能力：

- 启用或关闭命令守护。
- 管理黑名单命令。
- 管理白名单命令。
- 处理未分类命令。
- 添加自定义命令规则。

命令相关能力主要用于识别危险操作，例如批量删除、敏感目录改动、可疑脚本执行等。

#### 保护目录

保护目录用于对重要路径进行安全保护。

典型用途：

- 保护项目目录。
- 保护 Agent 会话目录。
- 保护配置目录。
- 保护重要数据目录。

当受保护目录发生高风险操作时，TraceFence 会生成告警。独立分发版可提供更完整的本机操作能力，App Store 版会受系统沙盒限制。

### 4.3 Agent 工具箱

Agent 工具箱是面向 Agent 运维的功能集合。

当前包含四个角色化工具：

- 会话管家：备份用户选择的 Agent 会话，不包含凭证。
- 健康诊断：检查授权目录、会话完整性、磁盘空间和运行状态。
- 用量分析师：结合 Token 与会话数据，发现异常趋势。
- 安全审计员：验证配置和凭证状态，但不读取或展示密钥内容。

主要操作：

- 手动备份会话
- 重新诊断
- AI 分析

AI 分析会优先使用系统可用的 Apple Intelligence 能力做本机摘要，不需要用户额外配置第三方大模型。当前重点用于总结诊断状态、风险和下一步建议。

独立分发版还支持进程控制：

- 关闭 Agent
- 强制关闭 Agent
- 重启 Agent

所有进程控制都会弹出确认，避免误操作。

### 4.4 Agent 监控

Agent 监控用于查看本机 AI Agent 的操作记录。

它会把监控到的记录按 Agent、操作类型、时间和风险汇总展示。

常见记录包括：

- 文件创建
- 文件修改
- 文件删除
- 文件读取
- 命令执行
- 搜索操作
- 会话活动

可用能力：

- 查看近期操作记录。
- 按 Agent 聚合。
- 按操作类型聚合。
- 查看异常或高频操作。
- 配合 Agent 守护生成告警。
- 按保留时间自动清理旧记录。

### 4.5 Token 统计

Token 统计用于把本机 AI Coding 工具的 Token、模型、项目和会话归因放在一个视图里。

支持视图：

- 概览
- 项目
- 模型
- 会话
- 数据源

核心指标：

- 总 Token
- 输入 Token
- 输出 Token
- 缓存 Token
- 估算花费
- 使用趋势
- Top 模型
- 项目成本归因
- 会话明细

支持的数据源包括本机授权目录中的 AI 工具日志和状态文件，例如：

- Codex
- Claude
- Cursor
- Pi Agent
- Trae
- CodeBuddy
- Gemini 等本机日志格式

注意事项：

- Token 数据来自本机日志解析，某些 Agent 不一定完整记录用量。
- 如果源日志没有写入模型名，TraceFence 会标记为未知或未上报。
- 如果源日志写入了实验模型名，TraceFence 会按日志原始模型展示。
- 成本是本地估算值，不等同于账单。
- 数据不会上传。

### 4.6 Mac 清理

Mac 清理用于扫描和清理本机可释放空间。

主要能力：

- 本地扫描
- 增强扫描
- 智能清理
- 搜索文件
- 按分类过滤
- 按应用过滤
- 按风险过滤
- 批量选择
- 移入废纸篓

常见分类：

- 浏览器缓存
- 办公软件缓存
- AI 工具缓存
- 开发工具缓存
- 系统缓存
- 社交软件缓存
- 安装包
- 项目产物

风险等级：

- 安全：一般可以清理。
- 注意：建议查看说明后再清理。
- 危险：可能影响登录状态、项目运行或应用数据，默认不建议直接清理。

### 4.7 APP 管理

APP 管理用于查看和处理已安装应用。

主要能力：

- 扫描已安装应用。
- 展示应用大小、缓存大小和相关数据。
- 查看应用来源和路径。
- 执行基础卸载。
- 执行完整卸载。
- 清理应用缓存。
- 批量处理应用相关文件。

使用建议：

- 对不确定的应用，优先执行缓存清理。
- 完整卸载会影响应用数据，执行前应确认不再需要。
- 涉及账号、本地数据库或项目配置的应用，需要谨慎处理。

### 4.8 依赖管理

依赖管理用于查看开发环境中的依赖、包管理器缓存和工具链数据。

覆盖方向包括：

- Homebrew
- Node.js / npm / pnpm / nvm
- Python / pip / conda
- Rust / Cargo
- Go
- Docker
- Gradle
- Maven
- CocoaPods

主要能力：

- 识别本机依赖和缓存。
- 展示占用空间。
- 判断依赖是否与 AI Agent 或开发项目有关。
- 清理缓存。
- 辅助卸载不再使用的依赖。

### 4.9 其它工具

其它工具用于扫描隐藏目录、开发者数据、CLI 工具和 AI Agent 相关目录。

常见识别对象：

- 隐藏配置目录
- AI Agent 数据目录
- CLI 工具目录
- 包管理器目录
- 开发工具目录
- 项目产物目录

用途：

- 找出平时 Finder 不容易看到的大体积目录。
- 判断某个目录是否与 AI Agent、开发工具或系统组件有关。
- 辅助决定是否需要备份、保留或清理。

### 4.10 适配检测

适配检测用于检查应用和工具在当前 Mac 上的兼容性。

典型用途：

- 检查 Intel 应用。
- 检查 Universal 应用。
- 判断是否依赖 Rosetta。
- 发现可能需要更新或替换的旧工具。

它适合用于 Apple Silicon 迁移、系统升级前检查和开发环境整理。

## 5. 菜单栏功能

TraceFence 可以常驻菜单栏，方便用户不打开主窗口也能查看状态。

菜单栏包含三个主要 Tab：

- 额度
- Agent 监控
- 系统监控

### 5.1 额度监控

额度监控用于查看 Provider 官方额度，而不是单纯统计本机 Token。

当前重点支持：

- Codex 5 小时额度
- Codex 每周额度
- Codex 每月或周期额度
- Codex Spark 额度
- 速率重置次数和到期时间

对于 Claude、Cursor、OpenAI、Azure OpenAI 等 Provider，TraceFence 会根据本机安装、登录状态、API Key、CLI 可用性或浏览器会话状态判断是否可以读取额度。

如果无法读取，会显示可操作提示，例如：

- 未安装 CLI
- CLI 不在 PATH
- 未登录账号
- 没有可用浏览器会话
- 缺少 API Key
- 当前 Provider 暂不支持该读取策略

### 5.2 Agent 监控

菜单栏里的 Agent 监控用于快速查看近期操作。

展示内容：

- 操作总量
- Agent 数量
- 操作类型分布
- 最近操作
- 当前运行状态

适合用于持续观察，不需要频繁打开主窗口。

### 5.3 系统监控

系统监控用于查看基础设备状态。

展示内容包括：

- 磁盘概览
- 硬件概览
- 监控开关
- 安全设置入口

## 6. 设置

设置页包含多个分区。

### 6.1 功能

可配置：

- 是否启用菜单栏监控。
- 是否启用传感器监控。
- 是否启用操作监控。
- 关闭主窗口时是否保留菜单栏。

### 6.2 授权

独立分发版使用 License Key 激活。

授权能力：

- 48 小时试用。
- 购买 TraceFence Pro。
- 激活 License Key。
- 重新校验授权。
- 解绑当前 Mac。

购买、税务、发票和支付由 Lemon Squeezy 处理。TraceFence 只保存本机授权状态并进行校验。

### 6.3 外观

TraceFence 支持多套主题，每套都有浅色和深色模式。

当前主题：

- Porcelain White：默认纯白主题，偏干净、明亮、克制。
- Shield Origin：贴近 TraceFence 图标的蓝色盾牌主题。
- Aurora Cyan：早期青绿色科技主题。
- Rose Signal：粉色系主题。

主题会影响：

- 主界面背景
- 左上角图标背景
- Tab 图标背景
- 按钮颜色
- 状态色
- 深色模式适配

### 6.4 监控

可配置：

- 磁盘空间告警阈值。
- 清理时是否优先移动到废纸篓。
- 是否阻止自动清空废纸篓。
- 操作记录保留时间。

### 6.5 网络

网络模式：

- 互联网模式：允许检查更新和访问授权校验服务。
- 内网或离线模式：避免主动检查更新，适合受限网络环境。

### 6.6 语言

TraceFence 支持多语言界面。当前界面文案覆盖：

- 简体中文
- 繁体中文
- 英文
- 日文
- 韩文
- 马耳他语

部分第三方模型名、Provider 名、命令名和文件路径会保持原文，这是为了避免误解真实来源。

### 6.7 版本与更新

独立分发版支持从 GitHub Releases 检查更新。

目标流程：

- 检查新版本。
- 自动下载更新包。
- 校验更新包。
- 自动安装。
- 自动重启 TraceFence。
- 尽量保留已有文件夹授权。

App Store 版通过 App Store 更新。

## 7. 使用手册

### 7.1 首次安装

独立分发版：

1. 从 TraceFence 官网或 GitHub Releases 下载 DMG。
2. 打开 DMG。
3. 将 TraceFence 拖入 Applications。
4. 启动 TraceFence。
5. 如果系统提示安全校验，请确认下载来源是官方地址。

App Store 版：

1. 从 Mac App Store 安装。
2. 启动 TraceFence。
3. 按提示授权需要读取的数据目录。

### 7.2 首次设置

建议按以下顺序完成：

1. 选择语言。
2. 选择主题。
3. 选择网络模式。
4. 授权 AI Agent 数据目录。
5. 开启菜单栏监控。
6. 开启操作监控。
7. 独立分发版激活 License Key，或先使用 48 小时试用。

### 7.3 授权数据目录

当概览、Token 统计或 Agent 工具箱没有数据时，通常是因为目录还没有授权。

操作方式：

1. 打开概览或 Token 统计。
2. 点击重新授权或授权数据目录。
3. 选择对应 Agent 的本机数据目录。
4. 返回页面点击刷新或立即同步。

常见目录：

- `~/.codex`
- `$CODEX_HOME`
- `~/.claude/projects`
- `~/.pi/agent`
- Cursor、Trae、CodeBuddy 等工具的数据目录

### 7.4 查看 Agent 总览

进入概览页后，重点查看：

- 会话数量是否正常。
- 活跃 Agent 是否正常。
- 项目数量是否正常。
- Token 总量是否读取成功。
- 数据源是否有权限问题。

如果数据显示明显偏少，优先检查是否授权了完整目录。

### 7.5 查看 Token 和成本

进入 Token 统计：

1. 点击立即同步。
2. 查看概览指标。
3. 切换到项目，查看哪个项目消耗最多。
4. 切换到模型，查看模型维度成本。
5. 切换到会话，查看具体会话。
6. 切换到数据源，检查是否有目录未授权或无记录。

注意：模型名来自日志本身。看到陌生模型名时，应优先检查源日志，而不是直接判断为 TraceFence 生成错误。

### 7.6 查看 Provider 剩余额度

在菜单栏点击 TraceFence 图标：

1. 进入额度 Tab。
2. 点击刷新。
3. 查看 5 小时、每周、每月或 Spark 额度。
4. 查看剩余速率重置次数和到期时间。
5. 如果某个 Provider 显示黄色提示，按提示安装 CLI、登录账号或配置 API Key。

额度监控依赖 Provider 官方接口、本机 CLI 或登录会话。不同 Provider 的可读取能力不同。

### 7.7 清理磁盘空间

进入 Mac 清理：

1. 点击本地扫描或增强扫描。
2. 等待扫描完成。
3. 使用分类、应用、风险筛选。
4. 优先选择安全项。
5. 对注意或危险项先查看说明。
6. 点击智能清理。
7. 默认建议移入废纸篓，确认无误后再清空。

不建议直接清理：

- 仍在使用的项目缓存。
- 未确认用途的数据库。
- 浏览器登录数据。
- Agent 会话和配置目录。

### 7.8 管理应用

进入 APP 管理：

1. 扫描应用。
2. 查看应用大小和关联数据。
3. 对普通应用可执行基础卸载。
4. 对需要彻底删除的应用，可执行完整卸载。
5. 对不确定应用，优先只清理缓存。

### 7.9 管理开发依赖

进入依赖管理：

1. 扫描依赖。
2. 查看 Homebrew、Node、Python、Docker 等依赖占用。
3. 判断是否仍被项目使用。
4. 清理缓存或移除不再使用的依赖。

开发依赖可能影响项目构建，删除前建议确认项目不再依赖。

### 7.10 使用 Agent 工具箱诊断

进入 Agent 守护 -> Agent 工具箱：

1. 点击重新诊断。
2. 查看健康项、警告项、会话文件和运行实例。
3. 如果有警告，按提示修复。
4. 需要备份时点击手动备份会话。
5. 需要摘要时点击 AI 分析。

独立分发版可以在这里对运行中的 Agent 执行关闭、强制关闭或重启。

### 7.11 备份会话

会话备份用于保存用户选择的 Agent 会话文件。

使用方式：

1. 打开 Agent 工具箱。
2. 点击手动备份会话。
3. 选择需要备份的数据源。
4. 选择保存位置。
5. 等待备份完成。

备份不会包含凭证、密钥或 Cookie 明文。

### 7.12 导出审计材料

在 Agent 守护中可以导出：

- 操作记录 CSV
- 操作记录 JSON
- 告警 CSV
- 审计报告

适合用于：

- 排查异常操作。
- 提交问题反馈。
- 团队内部审计。
- 清理或修复前留档。

### 7.13 更新 TraceFence

独立分发版：

1. 打开设置。
2. 进入版本与更新。
3. 点击检查更新。
4. 有新版本时点击更新并重启。
5. TraceFence 会自动下载、校验、安装并重启。

App Store 版：

1. 打开 App Store。
2. 在更新中安装 TraceFence 新版本。

## 8. 常见问题

### 8.1 概览页没有数据

可能原因：

- 没有授权数据目录。
- Agent 数据目录不是默认路径。
- 该 Agent 没有产生本机日志。
- App Store 沙盒限制了读取范围。

处理方式：

- 点击重新授权。
- 选择完整的 Agent 数据目录。
- 在 Token 统计的数据源页查看读取状态。
- 必要时给 TraceFence 完整磁盘访问权限。

### 8.2 Token 数比预期少

可能原因：

- 只授权了一部分目录。
- 某些会话没有写入 usage 字段。
- 某些 Provider 不提供完整本机日志。
- 日志被清理或迁移。

处理方式：

- 检查授权目录是否包含所有历史会话。
- 查看 Token 统计的数据源页。
- 对比源日志中的实际记录。

### 8.3 Provider 额度读取失败

可能原因：

- CLI 未安装。
- CLI 不在 PATH。
- 未登录 Provider 账号。
- API Key 未配置。
- 浏览器会话不可读。
- Provider 当前没有可用读取策略。

处理方式：

- 按黄色提示安装或登录。
- 检查命令行工具是否可直接运行。
- 配置对应 API Key。
- 授权完整磁盘访问权限。
- 刷新额度。

### 8.4 菜单栏点击后弹窗慢或打不开

建议：

- 更新到最新版本。
- 避免在大量扫描期间频繁点击菜单栏。
- 如果旧版本卡住，退出后重新打开 TraceFence。
- 保持菜单栏监控和操作监控开关状态正常。

### 8.5 更新后又要求授权目录

文件夹授权依赖 macOS 安全机制。TraceFence 会尽量保留授权，但以下情况可能导致重新授权：

- App 的签名或 Bundle ID 改变。
- 从不同来源安装。
- 手动删除了应用容器数据。
- macOS 重置了安全授权。

建议始终从同一官方渠道更新。

### 8.6 系统提示无法验证开发者

独立分发版应使用已经签名和公证的包。如果仍出现该提示：

- 确认下载来源是官方 GitHub Releases 或官网链接。
- 下载最新版本。
- 避免使用被重新打包或损坏的 DMG。

### 8.7 为什么会出现陌生模型名

TraceFence 的模型统计来自本机日志。模型名通常由 Agent 或 Provider 写入，TraceFence 会尽量保留原始值。

如果看到陌生模型名，可能是：

- Provider 实际返回了该模型名。
- Agent 使用了内部路由模型。
- 日志字段被实验版本写入。
- 老日志或缓存仍被统计。

需要判断真伪时，应查看源日志和解析缓存。

## 9. 推荐使用流程

### 日常使用

1. 菜单栏查看 Provider 额度。
2. 概览页查看会话、项目和 Token。
3. Agent 监控查看近期操作。
4. 发现异常后进入 Agent 守护处理告警。

### 每周维护

1. Token 统计查看项目和模型消耗。
2. Mac 清理扫描可释放空间。
3. APP 管理检查不用的应用。
4. 依赖管理清理开发缓存。
5. 导出必要的审计记录。

### 高风险操作前

1. 先备份 Agent 会话。
2. 先导出操作记录。
3. 清理时优先选择安全项。
4. 对危险项逐条确认。
5. 进程关闭或重启前确认当前任务已经保存。

## 10. 面向官网的功能摘要

TraceFence 可以对外描述为：

> TraceFence 是一款面向 AI Agent 用户的 macOS 本机控制台。它能聚合 AI 会话、项目、Token、Provider 额度、文件操作、Agent 运行状态和磁盘空间，让用户在一个原生应用里完成监控、诊断、备份、清理和安全审计。

核心卖点：

- AI Agent 会话与项目统一概览。
- Codex 等 Provider 官方额度监控。
- Token、模型、项目和会话成本归因。
- Agent 文件操作监控与告警。
- 会话备份、健康诊断和安全审计。
- Mac 清理、应用卸载和开发依赖管理。
- 本机优先，不上传私密会话内容。
- 独立分发版支持自动更新和 License Key 授权。
