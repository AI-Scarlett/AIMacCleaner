Preferences

Settings

Settings should feel operational and trustworthy, not like default macOS form controls dropped into the app.
Reset
Save changes
Monitor at launch

Start AgentGuard monitoring when the app opens.

Approval notifications

Show a clear prompt when AI tools touch protected files.

Theme

Default to the bright icon-aligned theme. Dark mode can exist later, but should not be the primary design direction.

Trusted Agents

Codex, Claude Code, Cursor, Gemini CLI, and custom tools can share the same profile card pattern.

Export

Use concise export controls with readable status, not raw technical settings first.

Privacy

Explain local-only monitoring and sandbox boundaries in plain language.
