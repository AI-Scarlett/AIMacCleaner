# TraceFence 1.2.19 发布记录

日期：2026-09-07。状态：宿主、两个插件与签名目录均已正式发布。

## 发布内容

- 宿主 1.2.19 (140)：修复额度监控停止后残留订阅和旧回调重新启动采样的问题。
- Quota Monitor 1.0.15：后台执行旧版 Touch Bar 迁移，修正 AppleScript 引号，支持取消和超时。
- Disk Cleanup 3.5.1：修复失效哈希缓存导致的重复文件误判，按块检查扫描预算，提前去重硬链接。

宿主和插件独立更新。既有价格、权益、权限及最低宿主版本策略保持原值。
