# Disk Cleanup 3.5.2 发布与验收记录

日期：2026-09-07。状态：插件与签名目录已正式发布，本机 TraceFence 1.2.19 (140) 已安装并完成实际清理验收。

## 问题与修复

| 问题 | 修复后行为 |
| --- | --- |
| 分类显示可清理，但点击复选框后仍为 0 项 | 默认推荐仍只选择低风险且可本地重建的项目；明确点击分类时，非默认项目先展示路径、大小和恢复影响，确认后选择当前已复核的可清理项目。 |
| 全局删除方式只修改缓存区域，其他区域继续使用旧模式 | 废纸篓/永久删除同步全部五个清理控制器；任一区域忙碌时整体拒绝更改，避免部分区域改变。 |
| 开发产物、安装包执行后没有明确结果 | 统一显示成功、跳过、未完成及具体原因，并提供重新扫描入口。 |
| 中途停止丢失已完成项目的反馈 | 当前原子操作完成后停止下一项，并保留已完成回执。 |
| 文件估算大小被误认为实际释放空间 | 按文件系统卷采样清理前后可用空间，显示带符号的观测差值；估算大小单独展示，采样不完整时明确不可用。 |
| 扫描过期或清理结束后按钮变灰，没有清楚的下一步 | 明确显示重新扫描和失效原因，操作摘要可换行，完成后重新扫描确认剩余内容。 |

分类选择只覆盖当前已复核项目，后来出现的项目不会继承选择。受保护路径、白名单、未完成的扫描结果、文件身份复核、5 分钟扫描有效期和永久删除确认机制继续生效。

## 验证

- 443 项 DiskClean XCTest 全部通过，0 失败；46 条扫描规则校验和 18 项 marketplace 测试通过。
- Release 支持 arm64/x86_64，PluginKit ABI 4；签名身份和目录矩阵验证通过。
- 最终包苹果公证 Accepted，submission ID：`b93e9052-c948-47f1-9ec3-ea7b3fc0008a`。
- 本机实际界面完成分类复核、7 项勾选、全部取消、仅选择测试产物、全局模式同步、清理及重新扫描。
- 实际清理将测试工程的 dist 与 node_modules 两项移入废纸篓，结果为成功 2、跳过 0、未完成 0；源码哈希未变，Git 状态干净。
- 界面分别显示文件估算 25.2 MB 与可用空间观测变化 +295 KB，并明确废纸篓不会立即释放空间；再次扫描后测试项目消失，原有 5 项约 750.4 MB 保留且未选中。
- 测试扫描根已移除，恢复用户原有三个工程扫描目录。

手工永久删除点击曾被自动审批拒绝，原因是不可恢复且缺少当次明确授权；该操作没有执行。实际界面验收改用可恢复的废纸篓方式完成，永久删除核心行为由文件系统 XCTest 覆盖。
