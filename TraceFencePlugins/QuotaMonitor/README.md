# TraceFence Quota Monitor

这是独立的额度监控插件。额度读取、前台 Agent 识别、手动切换和 Touch Bar 渲染都由插件自身完成；
它不修改 TraceFence 的菜单栏、任务栏、窗口布局或发布包。

## 原生 Touch Bar

`1.0.13` 在插件内注册一个常驻的系统 Control Strip **AI（sparkles）**入口，不依赖 BetterTouchTool、Node、Shell Script Widget 或自动化权限。入口在插件启动时就注册：即使用户点隐藏按钮收起额度显示、或随后重启 TraceFence，仍可直接在 Touch Bar 右侧 Control Strip 中点击 AI 图标重新打开。

展开时只占左侧一块紧凑区域，与 macOS 原有的右侧 Control Strip 共存；**一屏只显示一个 Agent 的一条额度**，不会把全部 Provider 或四条进度条硬塞到同一行：

`[循环 Agent]  GPT  自动跟随  |  5 小时  ━━━━━━━ 72%   2/4 ›   ×`

- 左侧 `arrow.triangle.2.circlepath`（循环箭头）是唯一的 Agent 切换入口；每点一次切到下一个可读取 Agent，并进入**手动锁定**。不在 Touch Bar 弹下拉菜单。
- 自动状态使用 `scope` 图标和“自动跟随”；手动状态使用 `pin.fill` 和“手动锁定”。点“手动锁定”立即恢复跟随当前前台 Agent。
- 每个 Agent 的所有额度窗口都可显示：5 小时、周额度、月额度或 Provider 返回的额外额度。只有一条时隐藏页码按钮；有 3、4 条时显示 `1/4 ›`，每点一次循环到下一条，最后一条回到第一条。
- 每一条都直接使用额度服务提供的真实窗口名称，和任务栏弹窗一致；例如多个五小时窗口或 `Current week (Opus)` 不会被压扁成同一个“5小时额度”。
- 进度条是 8pt 的扁平轨道，没有玻璃高光或立体填充；余量低于 20% 红色、20–49% 橙色、50–69% 黄色、70% 及以上绿色。
- 额度名称默认以 12pt 单行垂直居中显示；仅当放不下时才逐级缩小并按自然断点自动换行，不插入固定换行、不加“2/3”后缀，也不显示省略号。
- 所有文本都在各自可用区域内按字体行高垂直居中；Provider、百分比与空状态不再依赖手写 `y` 偏移。
- 末端的 `eye.slash` 是 22pt 的小型**隐藏**按钮，立即恢复默认 Touch Bar；重新打开的方法是点右侧 Control Strip 的 **AI（sparkles）**入口，也可从插件面板的“显示 Touch Bar 额度监控”操作打开。
- Touch Bar 内部的可见文案、提示与辅助功能文本使用插件的本地化资源，并在宿主切换语言时刷新；内置英语、简体/繁体中文、德语、西语、法语、日语、韩语、葡语、俄语与阿语文案，马耳他语回退英文。Provider 返回的真实额度窗口名称保持原样，不会被错误翻译或合并；阿语使用自然文本方向。
- “自动跟随 / 手动锁定”使用同一套本地化资源，按钮宽度按当前语言的实际文字宽度自适应，避免英文、德语或阿语被中文宽度常量截断。

## 边界

- 不改变 TraceFence 宿主的菜单栏、任务栏、窗口或 DMG。
- 额度读取仅在本机进行，凭据和原始响应不上传。
- 插件内置并显式调用自己的 `codexbar` Helper；官网版宿主原有的菜单栏 / 弹窗额度读取仍使用其自身 Helper，两条读取链路互不依赖。
- App Store 渠道暂时保留原有内置实现，不安装可下载代码。

## 发布

插件包使用 TraceFence Developer ID 对 Helper 和内层 `.bundle` 分层签名，并发布到独立、
不可变的 GitHub Release。公开商城目录记录版本、下载地址、大小和 SHA-256。
